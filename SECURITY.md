# Kebijakan Keamanan

## Melaporkan kerentanan

Jangan membuka issue publik untuk celah keamanan. Gunakan fitur **Security advisories** di
halaman GitHub repo ini ("Report a vulnerability"), atau hubungi pemelihara secara privat.
Sertakan langkah untuk mereproduksi, versi yang terdampak, dan dampaknya.

## Cakupan

Fitur keamanan bawaan dijelaskan di [docs/security.md](docs/security.md), termasuk batasannya.
SimPy.ts adalah proyek awal (versi 0.x) dan belum diaudit secara independen.
